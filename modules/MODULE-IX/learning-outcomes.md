# Learning Outcomes

Students completing this module should be able to:

1. Define the Doctrine of Salvation using biblical and theological language.
2. Explain grace, faith, repentance, and sanctification.
3. Distinguish salvation from emotionalism or religious performance.
4. Explain surrender and perseverance within Christian discipleship.
5. Apply Mirror → Water → Fire to salvation and formation.
6. Analyze theological questions related to assurance and holiness.
7. Demonstrate competency through written reflection and discussion participation.
